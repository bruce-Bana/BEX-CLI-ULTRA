# Release Check
- Confirm entry points, package scripts, required Node version, and install instructions.
- Run syntax checks and automated tests.
- Check .gitignore and ensure no secrets or local artifacts are staged.
- Review breaking changes and migration notes.
- Verify the package version and CI workflow.
- Never merge or publish automatically unless explicitly authorized.
