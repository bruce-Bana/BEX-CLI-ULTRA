# Code Review
1. Identify the target scope and inspect the diff.
2. Trace affected callers and data flows.
3. Check validation, error handling, permissions, secrets, and edge cases.
4. Rank findings: critical, high, medium, low.
5. Suggest minimal fixes and verification commands.
6. Separate verified facts from hypotheses. Never claim tests ran unless they did.
