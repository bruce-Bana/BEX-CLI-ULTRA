# Bug Investigation
1. Reproduce or isolate the failure with the smallest safe test.
2. Follow inputs through parsing, state, providers, tools, and output.
3. Find the root cause instead of masking symptoms.
4. Add a regression test before or alongside the fix.
5. Run focused tests, then broader checks when practical.
6. Report the cause, changed files, validation, and remaining uncertainty.
